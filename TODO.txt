You're ready for chkdsk:
1. Close Visual Studio and this session.
2. In Terminal (Admin), run chkdsk D: /f.
3. Answer N to force a dismount, then Y to check the volume at the next restart.
4. Reboot.
5. Afterwards, run git submodule update --init --force vendor/cross-platform/bullet3 to restore the damaged Bullet folder.
